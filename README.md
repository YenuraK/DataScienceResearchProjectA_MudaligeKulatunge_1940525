# Data Science Research Project (Part A)

Part A of my Master of Data Science research project at the University of Adelaide, on **multidimensional opinion dynamics** — how groups update coupled beliefs over time across an influence network, using the framework of Ye et al. (2020).

This stage covered the foundational modelling, tooling and exploration that fed into Part B:

- **`generateC.m`** / **`pseudo_generateC.md`** — generating valid per-agent reasoning (logic) matrices
- **`FJ_Opinion_Generator/`** — opinion / belief generation
- **`belief-dynamics-platform-viz/`**, **`belief-timeseries-viz-toolbox/`** — visualising belief trajectories over time
- **`Project Progress Report (Part A).pdf`** — the written progress report

➡️ The completed simulation, experiments and report figures are in **[opinion-dynamics-fitness](https://github.com/YenuraK/opinion-dynamics-fitness)** (Part B).

### Reference
Ye, M., Liu, J., Wang, L., Anderson, B.D.O. and Cao, M. (2020). *Consensus and disagreement of heterogeneous belief systems in influence networks.* IEEE Transactions on Automatic Control, 65(11), 4679–4694.
